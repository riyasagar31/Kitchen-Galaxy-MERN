# Kitchen Galaxy

A full-stack MERN application for online kitchen product ordering.

## Tech Stack

- React.js
- Node.js
- Express.js
- MongoDB
- Razorpay

## Features

- User Authentication
- Product Management
- Shopping Cart
- Online Payments
- Order Tracking

## Setup

### Backend

```bash
npm install
npm run server
```

### Frontend

```bash
npm install
npm run dev
```
